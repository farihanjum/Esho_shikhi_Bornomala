# 📚 Esho Shikhi Bornomala

**Esho Shikhi Bornomala** (Let's Learn Bangla Alphabets) is an interactive Android application designed to help children learn Bangla alphabets in an engaging and fun way.  
The app combines **colorful visuals**, **audio pronunciations**, and **touch-based interactivity** to make early language learning more enjoyable and intuitive for kids.

---

## 🌟 Features

- 🎨 **Interactive UI:** Simple, child-friendly interface with bright colors and large clickable buttons.  
- 🔊 **Audio Support:** Each alphabet is paired with its pronunciation to enhance auditory learning.  
- 🧩 **Visual Learning:** Each letter is accompanied by relevant images (e.g., “অ for অজগর”) to reinforce memory.  
- 📖 **Sequential Learning:** Alphabets are presented in the standard Bangla order, helping maintain logical flow.  
- 📱 **Offline Support:** The app works fully offline — no internet connection required.  
- ⚙️ **Lightweight & Fast:** Optimized for older Android devices.

## 🚀 Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/farihanjum/Esho_shikhi_Bornomala.git


2. **Open the project** in Android Studio.

3. **Build and run** on an emulator or Android device:

   * Minimum SDK: `API 21 (Lollipop)`
   * Target SDK: `API 33 (Android 13)`

4. Enjoy learning Bangla alphabets! 🎉
